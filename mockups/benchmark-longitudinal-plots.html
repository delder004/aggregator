Accounting AI benchmarks

Quick longitudinal plot sketches for the top three sources

These are directional plots only. Each benchmark has different tasks, scoring, model sets, and update cadence, so the useful read is within each chart rather than across charts.

Data posture

TaxCalcBench is the cleanest plot candidate. FinMaster has a sparse date column. DualEntry currently has two public result snapshots, so its line is more of an update log than a mature time series.

Generated as a local mockup from public benchmark tables and blog posts reviewed on June 1, 2026.
