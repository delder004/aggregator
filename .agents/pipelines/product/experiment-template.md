# Experiment: [name]

Run / hypothesis ID / plan version / prepared date / execution status.

## Claim and investment decision

Hypothesis, claim type, population/situation, offer and predicted behavior. Why this uncertainty matters to the vision; what accepting or rejecting would change. State what this experiment cannot establish.

## Smallest credible test

Method, concrete offer/specimen, best existing alternative or comparison, recruitment/sampling and channel. Explain why this test can answer the question before substantial building. Separate public interest, stated interest and observed behavior.

## Criteria recorded before execution

Primary outcome, numerator/denominator, exposure/sample target, window, accept criterion, reject criterion, inconclusive region and rationale. Note bias, confounds, data-quality checks and stop conditions. Small-sample practical rules are not significance tests. Avoid changing criteria after seeing results; preserve deviations.

## Execution and resources

Exact steps, owner, budget, evidence capture, privacy and required access. Distinguish available/authorized actions from missing access or authorization. Prepare needed materials; never imply outreach, posting or payment already happened.

## Results record (save separately as results.md)

Status: planned/running/completed/blocked. Actual actions/dates, exposure and qualifying observations, outcomes, failures/exclusions, evidence references, cost, deviations and limits. If no execution: not run, with exact blocker. Prior data analyzed retrospectively must be labeled exploratory.
