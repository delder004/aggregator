# 06_product_plan

Job: Product and growth plan.

Read the [root context](../CONTEXT.md). Write results under `<run>/06_product_plan/`.

## Inputs

All selected stage outputs; decision-template.md.

## Process

Write the self-contained final Markdown product proposal using the template. Lead with a compelling, specific direction and the reasoning behind it. Include a concrete example of the experience so the reader can judge its quality. Preserve the distinction between ambition, first release and experiment. Derive features and user stories from the chosen experience, with acceptance criteria, priorities, dependencies and growth contributions. Tell the reader what not to build and why.

Connect content, distribution, product usefulness, sharing and return behavior in an explicit growth model; identify accessible channels and missing access. Explain what accumulates with use or publishing, and what must be earned. Define measures for acquisition, useful outcomes and repeat use without invented forecasts or invalid identity assumptions. Include operating effort, evidence freshness, source quality and ownership assumptions; estimates are not observed costs. Carry forward decisive uncertainties concisely without burying the recommendation in repeated caveats. The final remains Proposed; no build, deployment or outreach is implied.

## Outputs

- `output/product-decision.md`: selected stage result.
- `handoff.md`: selected input/output links, judgment, unresolved issues and next stage.

## Human check

Continue authorized research without routine approval gates. Clearly distinguish user input from agent proposals; ask only when missing input materially blocks useful work.
