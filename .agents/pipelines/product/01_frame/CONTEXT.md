# 01_frame

Job: frame an open decision.

Read the [root context](../CONTEXT.md) first. Write this stage under `<run>/01_frame/`.

## Inputs

The user request, prior decisions and known constraints.

## Process

Record the original objective, geography, time horizon, candidate audience groups, budget, editorial/distribution capacity and nonnegotiable constraints in `output/brief.md`. Unknown capacity remains unknown; assess at least a low-capacity and a moderate-capacity scenario (e.g. 2 versus 8 editorial hours/week, explicitly hypothetical).

Do not choose a primary audience, category, feature or design yet. Ask consequential missing questions when needed; continue independently useful research. User approval to proceed is authorization, not evidence of user demand. Separate existing assets from constraints. Blank slate does not mean discarding indexed URLs or proven capabilities.

## Outputs

- `output/brief.md`: the selected stage result.
- `handoff.md`: links to inputs and selected outputs, conclusion/status, unresolved issues, and next stage.

## Human check

No routine approval is needed to continue authorized research. Record unresolved assumptions; ask only when missing information blocks useful work.
